# Security Policy

## Supported Versions

Security updates apply to the `main` branch and the current production deployment.

## Reporting a Vulnerability

Please report security issues privately by email to
[security@ethotechnics.org](mailto:security@ethotechnics.org), with the subject line
`[Vulnerability report]`, as the
[vulnerability disclosure policy](https://ethotechnics.org/security/vulnerability-disclosure)
and [`security.txt`](public/.well-known/security.txt) say. Do not open public issues for security
vulnerabilities.

When reporting, include:

- A detailed description of the issue and its impact.
- Steps to reproduce or a proof of concept.
- Any relevant logs, screenshots, or mitigations you have tried.

Kanav Jain reads these reports. There is no on-call rotation and no promised response time. A
reply says whether the report could be reproduced and what will change.
